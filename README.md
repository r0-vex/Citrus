 # 🍋 Citrus

> A lightweight personal homelab platform built on a repurposed Samsung Galaxy J7 Max using Termux.

---

## 📖 About

Citrus is my personal infrastructure platform designed for learning Linux, server administration, Python development, automation, and self-hosting.

The goal is to transform an old Android phone into a fully functional development server capable of hosting:

- 🤖 Python Bots
- 🌐 Web Applications
- 🎵 Personal Music Streaming
- 📊 Monitoring Dashboard
- 📁 File Services
- ⚙️ Automation Scripts
